# 清单、续跑与校验

## 两份清单

- `_discovery.json`：`--list-only` 的发现结果。枚举不得覆盖已有下载清单。
- `_manifest.json`：下载结果和文件认领信息，供下次在同一输出目录续跑。不要删除它来“清理日志”。

当前清单带 `schema_version: 1`。共有的核心字段包括 `resources` 和按资源状态汇总的 `statistics`；共享课另有 `folders`，智慧课程与学习通另有 `tasks`。平台特有的来源字段保留在各资源记录中，供排查章节、任务和活动遗漏。

清单可能保留下载 URL。即使控制台错误已对查询参数脱敏，也不能据此将整份清单视为公开安全。签名链接、课程标识和响应内容均应留在私有输出目录。

## 资源状态

| 状态 | 含义 | 交付时的处理 |
| --- | --- | --- |
| `discovered` | 仅枚举，尚未下载 | 只能报告发现结果 |
| `ok` | 本次下载并通过对应格式校验 | 计入下载成功 |
| `exists` | 复用清单认领的已验证文件 | 单独说明复用数量 |
| `skipped_video` | 按默认范围跳过视频 | 有意跳过 |
| `skipped_non_document` | 类型不在候选白名单 | 说明格式不支持 |
| `skipped_unsupported_format` | 候选格式目前没有受支持的验证器 | 不计作成功下载 |
| `skipped_ebook` | 平台电子书未提供可下载直链 | 说明平台限制 |
| `permission_denied` | 平台明确不允许下载 | 说明权限限制，整轮非零退出 |
| `failed` | 请求、文件校验或其他处理失败 | 保留原因，整轮非零退出 |

`statistics` 中各状态数量之和应与 `resources` 条数一致，但资源计数不能单独证明目录已完整遍历。共享课检查每个目录的状态；智慧课程检查任务的预期活动数、已访问数与任务状态。

任务的 `locked` 与 `no_activities` 是已识别的正常分支，分别表示平台锁定和空任务；`incomplete` 与 `failed` 表示遍历未完成。整轮退出 `0` 不代表锁定任务也已取回，交付仍需说明。

## 本地文件验证

```sh
course-resource-download verify ./downloads/course --recursive
course-resource-download verify ./downloads/course --recursive --json
```

| 格式 | 当前校验能力 |
| --- | --- |
| PDF | 签名、严格解析与内容流解码，页数大于零；加密 PDF 无密码时拒绝 |
| PPTX / DOCX / XLSX | ZIP 校验、XML 与内部关系结构；PPTX 至少一个被引用的幻灯片，XLSX 至少一个有效工作表，DOCX 有正文节点 |
| TXT | UTF-8 文本及明显非文本错误响应检查 |
| PPT / DOC / XLS（旧版 OLE） | 暂不支持完整性校验 |
| 视频及其他格式 | 暂不支持校验 |

格式验证不等于病毒扫描、教材内容核对或每页视觉验收，也无法发现平台没有列出的资料。下载适配器只有在验证成功后才将文件登记为 `ok`；不支持的候选格式记录为跳过。

独立 `verify` 跳过两份工具清单、锁文件与 `.part` 临时文件，其他本地文件均尝试验证。不支持的格式或空目录返回 `1`。将人工说明和其他日志放在课件输出目录之外，可避免把它们误当成待验证课件。

## 下载与续跑保证

文件使用目标目录内的临时 `.part` 文件写入；下载结束后按目标扩展名验证，成功才原子替换目标。请求失败、内容截断、超过大小上限或格式不符时，不应把临时内容替换成最终文件，也不应破坏已有目标。

资源认领信息从下载清单恢复。已认领且通过验证的文件可复用；同名不同来源另行分配文件名。没有清单时无法可靠判断旧文件归属，可能产生带后缀的新文件。平台签名 URL 变化也可能影响以 URL 为依据的识别，不能承诺任意跨会话链接都可去重。

同一输出目录只允许一个写入进程。`.download.lock` 由操作系统提供互斥，锁文件可持久存在；文件存在不代表锁仍被持有，进程退出后操作系统释放锁。不要手工删除锁文件：删除文件会使其他进程锁住不同文件，破坏互斥。

清单先写临时文件再原子替换，避免写到一半留下截断 JSON。这并不保证强制终止或断电前的最后一个资源一定已记入清单；异常中断后应在原目录重跑并重新对账。
