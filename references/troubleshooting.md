# 故障排查

先记录命令退出码，查看对应清单中的 `failed`、`permission_denied`、目录失败和任务 `incomplete`。分享报告时删除查询参数、账号、课程标识、Cookie 与文件内容。

| 现象 | 检查与处理 |
| --- | --- |
| 命令找不到或模块不能导入 | 在项目根目录安装 `python -m pip install -e '.[browser]'`，确认命令与安装使用同一 Python；可改用 `python -m course_resource_download` |
| 找不到浏览器或 Playwright 模块 | 安装 `[browser]` 后执行 `python -m playwright install chromium`；本地验证不要求浏览器 |
| 登录后下载仍要求登录 | 确认登录与下载使用同一 `--state`；默认路径相对当前工作目录；会话过期时重新人工登录 |
| 页面停留在验证码 | 默认由用户人工完成；自动求解需显式选项与 `[captcha]`，其结果不保证成功；失败后检查错误，不无限重试 |
| 共享课报告无下载权限 | 历史 `candownload=1` 对学生表示禁止；确认当前页面真实下载权限，不能用备用接口绕过 |
| 共享课目录“进入成功”却列表没变 | 检查文件夹链接、实际路径与表格；行点击成功不证明导航完成 |
| 智慧课程页空白 | 确认是学生端路径，课程和班级标识有效；教师端 `/course/*` 不能替代学生端 |
| 智慧课程只访问了首个活动 | 检查锁定状态、末页箭头类、活动身份 `(documentId, taskId)` 与迟到响应；保留 `incomplete` 结果 |
| PDF 实际是登录页或预览 HTML | 文件校验应拒绝；确认获取的是下载直链，检查会话与权限，不手动改扩展名蒙混通过 |
| 视频或旧版 Office 被跳过 | 当前没有受支持的验证器，状态为 `skipped_unsupported_format`；`--include-video` 不提供完整视频支持 |
| 已有文件再次另存 | 保留并检查 `_manifest.json`；清单缺失、来源 URL 变化或旧文件验证失败都可能影响复用 |
| `.download.lock` 一直存在 | 锁文件持久存在是正常情况。确认其他进程是否在运行，不要删除文件来解锁；进程退出后操作系统会释放锁 |
| 中断后有 `.part` 文件 | 原目录续跑并检查清单；清理前确认没有活动下载进程，不要把 `.part` 手动改成最终文件 |
| 文件看似全下了但退出 `1` | 文件验证无法证明目录完整；检查权限拒绝、失败目录、超限活动和任务状态 |

如怀疑平台改版，用最小授权课程复现，记录版本、日期、系统类型、脱敏错误和必要的页面结构。添加合成回归样本后再修改适配器；不要提交原始网络响应或登录截图。
